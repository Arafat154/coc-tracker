# Clash Ledger 1.2.0

- **Compact widget:** progress rings around game icons, one countdown per upgrade, no scrolling. The grid adapts to size and shows a “more” count for overflow. Tap an icon to manage that upgrade.
- **OLED theme:** pure black app and widget backgrounds, with the original navy theme still available.
- **Next lab:** the third dashboard card now shows the next normal research completion. It follows Star Laboratory on the Builder Base tab and accounts for boosts/helpers.
- **Multiple villages:** import different player tags, then switch between saved accounts. Reimporting updates only that tag. Each village keeps its own boosts, helpers and timers; reminders continue across saved villages.
- **Artwork fixes:** added Logger, Longshot and Smasher, plus missing spell/trap icons including Totem Spell and Giga Bomb.
- **Upgrade safety:** existing village data migrates automatically; 65 unit tests plus API 36 emulator validation.

Find layout and theme controls under **Settings → Appearance & widget layout**. Use **Switch village** on the overview card to change accounts. Widgets follow the selected village.

These are local tracker profiles, not Supercell ID logins. New in-game actions still need a fresh export or manual edit. Widget progress refreshes remain subject to Android battery scheduling. Matching art for Helper Hut, Crafting Station and a few older items is still unavailable in the current artwork catalogue.
