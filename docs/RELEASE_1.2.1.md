# Clash Ledger 1.2.1

Adds a **⇄ switch village button** beside refresh in both compact and detailed widgets. With two or more saved villages, each tap selects the next account and wraps back to the first, without opening the app.

All widgets follow the selected village. Each village’s timers, boosts and helper assignments stay separate; reminders continue for all saved villages. With one village, the switch button stays hidden.

Includes all [1.2.0 features](RELEASE_1.2.0.md): compact progress rings, OLED black theme, next-research summary, multiple villages and Guardian artwork fixes.

69 unit tests pass, with successful debug build and lint checks. Existing data is preserved when installing this APK over a compatible signed build.
